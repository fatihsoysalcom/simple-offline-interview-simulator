# Simple Offline Interview Simulator

This example demonstrates a basic, offline text-based interview simulator, mimicking the "Interview Buddy" concept. It uses predefined questions and simple keyword-based feedback to simulate an AI interviewer. The user interacts by typing responses in the console, showcasing a fundamental approach to an offline AI-powered conversational agent.

## Language

`python`

## How to Run

Save the code as `main.py`.
Open a terminal or command prompt in the same directory.
Run the script using `python main.py` and follow the prompts.
